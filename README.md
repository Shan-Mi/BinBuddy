# 🗑️ Bin Buddy

Bin Buddy helps neighbors never miss trash day again with quick, automatic email and SMS reminders — because no one likes an overflowing bin!

🚀 Features (in progress):

- [ ] ✨ Magic Link Login – Sign in easily and securely; join the right family group using a join code.

- [ ] 📱 Persistent Device Data – Remember user info and settings across sessions.

- [ ] 🔁 Swap Responsibilities – Allow a one-time handoff of bin duties to another neighbor. (Need approval from second party in order to swap)

- [ ] ⏰ Automated Reminders – Send friendly email/SMS nudges every Monday evening to the current bin buddy.

- [ ] 🎨 UI Improvements – Make everything cleaner, clearer, and more delightful.
